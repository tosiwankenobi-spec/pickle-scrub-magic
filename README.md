# Pickle Polish

Storage cleanup app built with TanStack Start, React 19, Tailwind CSS v4, and Capacitor (Android). Originally developed in [Lovable](https://lovable.dev); this README covers running and continuing development outside Lovable (e.g. with Claude Code, Cursor, or any editor).

## Requirements

- [Bun](https://bun.sh) (or npm/pnpm — commands below use bun)
- Node.js 20+
- For Android builds: Android Studio + JDK 21 (see `ANDROID_BUILD.md`)

## Getting started

```bash
bun install
bun run dev          # http://localhost:8080
bun run build        # production build
bun run preview      # preview production build
bun run lint
bunx vitest run      # unit tests
```

## Project structure

- `src/routes/` — file-based routes (TanStack Router). Root layout: `src/routes/__root.tsx`. Do not edit `src/routeTree.gen.ts` — it is regenerated by the router plugin.
- `src/components/` — UI components (shadcn/ui + custom).
- `src/lib/` — pure helpers and app logic (e.g. `scan-announcements.ts`).
- `src/styles.css` — Tailwind v4 config via `@theme`.
- `src/server.ts` — SSR/Worker entry.
- `capacitor.config.ts`, `android/` — native Android shell.

## Environment / secrets

This project currently has no runtime backend secrets. If you add server-side integrations, create a `.env` file locally (git-ignored) with variables read via `process.env.*` inside server functions or `src/routes/api/*` handlers. Client-exposed variables must be prefixed `VITE_`.

If you previously used Lovable Cloud / Lovable AI features, you'll need to swap them for your own backend:
- **Lovable Cloud** → your own [Supabase](https://supabase.com) project (Lovable Cloud is Supabase under the hood).
- **Lovable AI Gateway** → direct provider (OpenAI, Google, Anthropic) with your own API keys, or a gateway like OpenRouter. See any `createLovableAiGatewayProvider` usage and replace the base URL + auth header.

## Deployment

The app builds to a Cloudflare Workers–compatible bundle by default (via TanStack Start + nitro). You can also deploy to Vercel, Netlify, or Node hosting by adjusting the nitro preset in `vite.config.ts`. Static hosts won't work because routes rely on SSR.
